# 🍜 吃什么？

> 今天吃什么？看看别人吃了什么！

## 🎯 项目简介

帮助用户解决「今天吃什么」的难题，匿名记录食物 + 查看别人吃了什么 + 统计排行。

## ✨ 功能特性

- 📝 **记录食物** - 匿名提交今天吃的食物
- 📊 **实时 Feed 流** - 查看别人最近吃了什么
- 🔥 **今日排行** - 统计热门食物排行榜
- 📈 **数据统计** - 今日人次、食物种类一目了然
- 🔄 **每日重置** - 每天 0 点自动刷新数据

## 🚀 快速开始

### 安装依赖

```bash
npm install
```

### 启动服务

```bash
npm start
```

### 访问

- 本地：http://localhost:3001
- 公网：http://82.157.191.32:3001

## 🛠️ 技术栈

- **前端:** Vue3 + TailwindCSS
- **后端:** Node.js + Express
- **数据库:** SQLite
- **部署:** 腾讯云 Lighthouse

## 📁 项目结构

```
chishenme/
├── server.js          # 后端服务器
├── package.json       # 项目配置
├── food.db           # SQLite 数据库（自动创建）
└── public/
    └── index.html    # 前端页面
```

## 🔌 API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/food` | POST | 提交食物 `{ food: string }` |
| `/api/foods` | GET | 获取今日食物列表 |
| `/api/stats` | GET | 获取今日统计和排行 |
